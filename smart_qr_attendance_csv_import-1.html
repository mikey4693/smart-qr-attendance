The scanner tries the QR text as a register number, then checks the last URL segment (including Base64-encoded IDs). It does not access the college website.

Prototype limitations

Records are stored only in this browser using localStorage; they do not sync between devices. A QR code can be copied and does not prove who is holding the card. Use real student data only with permission. For production, add a secure backend, teacher authentication, and authorization.
